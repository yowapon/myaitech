# myaitech — オリジナル教材ライブラリ

AIと一緒に作った、図解つきの学習教材と練習アプリのコレクションです。

1本ずつが **1枚のHTMLで完結** していて、外部のCDNやライブラリを一切読み込みません。ダウンロードしてオフラインで開いてもそのまま動きます。

- **読む教材**（`02.kyozai/`）— インラインSVGの図解・3択の理解度クイズ・目次サイドバー・ダークモード切替
- **練習アプリ**（`03.apps/`）— 手を動かして身につけるためのもの。記録は端末のなかだけに保存され、外部には送信しません

## 📖 読む

**→ [https://yowapon.github.io/myaitech/](https://yowapon.github.io/myaitech/)**

> GitHub Pages が未設定の場合は、リポジトリの **Settings → Pages** で Source を `main` / `/ (root)` に設定すると公開されます。ローカルで読む場合は、リポジトリをクローンして [`index.html`](index.html) をブラウザで開いてください。

## 🗂 リポジトリ構成

```
.
├── index.html          # 扉ページ（分野別リンク集）
├── 01.skills/          # 作業に使っている Claude Code スキル（zip）
├── 02.kyozai/          # 読む教材
│   ├── 001.パスキー入門/
│   │   ├── パスキー入門_企画.md      # 設計メモ（構成・図解案・出典）
│   │   └── パスキー入門_教材.html    # 教材本体
│   ├── 002.株基礎知識/
│   ├── 003.steamゲーム開発流れ/
│   ├── 004.AIエージェント/
│   ├── 005.新NISA/
│   ├── 006.生成AIのハルシネーション/
│   ├── 007.AIエージェントの文脈引き継ぎ/
│   └── 008.AppStoreアプリ開発流れ/
└── 03.apps/            # 練習アプリ
    └── 001.フラッシュ暗算ｘ履歴分析/
        ├── フラッシュ暗算ｘ履歴分析_要件定義.md   # 仕様（先に決めたもの）
        └── フラッシュ暗算ｘ履歴分析_アプリ.html   # アプリ本体
```

教材フォルダ・アプリフォルダは、それぞれ追加順に `001.`, `002.`, … と連番で増えていきます。扉ページ（`index.html`）では番号順ではなく **分野ごと** に並べ替えて掲載しています。

各フォルダの `*_企画.md` は、その教材をどういう順番で・どの図で理解させるかを決めた設計メモです。教材そのものより先に書いています。

## 🛠 どう作っているか

[`01.skills/original-kyozai.zip`](01.skills/) は、テーマを渡すと **Webリサーチ → 教材企画（.md）→ ビジュアル教材（.html）** の順に作り切る Claude Code 用のスキルパッケージです。この教材群はすべてこのスキルで作っています。

各教材の末尾には、根拠にした一次情報（公式ドキュメント・統計・報道）のURLを出典として全て載せてあります。

## ⚠️ 注意

学習用に作った資料です。内容は作成時点の情報に基づいており、制度・料金・仕様は変わります。実際の判断に使う場合は、各教材末尾の出典から一次情報を確認してください。

練習アプリの記録は、ブラウザの保存領域（IndexedDB）にのみ保存されます。外部への送信は一切ありません。そのぶん、ブラウザの閲覧データを削除すると消えます。iPhone・iPad の Safari では、7日間開かないと自動的に削除されることがあるため、ホーム画面に追加しておくか、アプリ内のバックアップ機能で書き出しておいてください。
