# 教材企画: AIと始めるSNS運用代行 — 副業ゼロからの実務ガイド

## 0. 前提

- **対象読者**: 在宅で副業を始めたい主婦。SNSは「見る側」としては使うが運用したことがない。副業経験もなし
- **想定レベル**: 完全な初心者。マーケティング用語も業務委託の常識も未知。ただしスマホとPCの基本操作はできる
- **AIの前提**: Claude Pro か ChatGPT Plus のどちらか1つ（月3,000円前後）に契約する。**AIツール自体もほぼ未経験**なので、「プロンプト」の意味から扱う
- **所要時間**: 35〜40分
- **分量方針**: ユーザーが分量超過を明示的に許可。本文 6,000〜7,000字を目安とする（標準の2,500〜3,500字を意図的に超える）

### 読了後にできるようになること

1. SNS運用代行が「誰から・何を頼まれて・いくらもらう仕事か」を自分の言葉で説明できる
2. AIに任せる作業と自分でやる作業の線引きができ、最初のプロンプトを実際に打てる
3. 扶養・確定申告・契約という3つの地雷を避けたうえで、最初の1件までの手順を紙に書ける

### この教材が取らない立場

「未経験から月30万」のような煽りは書かない。実際の初期単価は月3,000円〜1万円の水準から始まるので、そこを最初に見せる。夢を売る教材ではなく、**始めた人が3か月で辞めない**ための教材にする。

---

## 1. 全体像 — この仕事の地図

- **図解案**: ループ図。「依頼主（お店・小さな会社）」→「あなた（運用代行）」→「SNSアカウント」→「数字（フォロワー・保存・来店）」→ 依頼主に戻る、の4点の循環。中央に「AI＝下書き係」を小さく置く
- **伝えること**:
  - 運用代行は「投稿を作って出す人」ではなく「依頼主の代わりにアカウントを育てる人」
  - 報酬の根拠は投稿枚数ではなく、依頼主が自分でやらずに済んだ時間と、数字の変化
  - AIはこのループの中の1工程（下書き）に入るだけで、ループ全体を回すのは人間
- **クイズ**: なし

## 2. 何を代行するのか — 業務の6ブロック

- **図解案**: 分解ツリー。「SNS運用代行」を6つに分解 — ①企画（何を投稿するか決める）②制作（画像・文章を作る）③投稿（出す・予約する）④コメント返信⑤分析（数字を見る）⑥レポート（依頼主に報告する）。各ブロックの下に「AI度」を小さく表示
- **本文で補う内容**:
  - 案件は「全部やる」より「一部だけ」の方が多い。初心者は②③④から入るのが現実的
  - ①企画と⑥レポートが単価を決める。ここができると価格が跳ねる
  - 「投稿だけ」で受けると、あとから①や⑤を無償で求められがち（→ 契約の章に接続）
- **クイズ**: なし

## 3. いくらもらえるのか — 相場の階段

- **図解案**: バーチャート（横棒4本）。①クラウドソーシングの初心者案件（月3,000〜1万円）②副業で1〜3アカウント（月1万〜10万円）③投稿代行の会社相場（月10万円以下）④運用全般の会社相場（月20〜30万円）。①と③のあいだに「ここが谷」と注記
- **本文で補う内容**:
  - ネットで見る「月20〜40万円」は**会社が会社に出す値段**。個人の副業初期とは別の市場
  - 最初の3〜6か月は月3,000円の案件を5件で月1.5万円、という水準が普通
  - 単価が上がるのは「実績の数」ではなく「レポートで数字を説明できるか」
  - 出典: 費用相場の記事群、フリーランス始め方記事
- **クイズ**: なし

### → クイズ1（相場の理解）

「月20〜40万円という相場を見た。副業初心者の自分も最初からこれくらいもらえる？」の3択。誤答肢に「実績を作れば1件目から可能」「地域による」を置く。

## 4. どのSNSを選ぶか

- **図解案**: バーチャート。総務省 令和6年度調査の全年代利用率 — LINE 91.1% / YouTube 80.8% / Instagram 52.6% / X 43.3% / TikTok 33.2% / Facebook 26.8%。Instagram と X と TikTok に「代行案件が多い」印を付ける
- **本文で補う内容**:
  - 利用率1位のLINEは代行案件が少ない（公式アカウント配信は別スキル）。**利用率と案件数は一致しない**
  - 初心者が入りやすいのは Instagram。飲食・美容・教室など小規模事業者の需要が厚い
  - 1つに絞る。複数を薄く触るより、1媒体で1年分の勘を持つ方が売り物になる
  - 出典: 総務省 令和6年度 情報通信メディアの利用時間と情報行動に関する調査
- **クイズ**: なし

## 5. AIをどこに置くか — 任せる / 任せない

- **図解案**: 2×2マトリクス。縦軸「間違えたときの被害（大／小）」、横軸「手数の多さ（多い／少ない）」。右下（手数が多い×被害が小さい）に「AIに全部任せる＝投稿文の案出し、ハッシュタグ、返信の下書き」。左上（被害が大きい）に「人が決める＝依頼主の事実確認、価格・効能の記述、投稿の最終ボタン」
- **本文で補う内容**:
  - AIは「思いつく速さ」を代行する道具で、「責任」は代行できない
  - 具体的に危ないのは、AIが知らない事実を書いてしまうこと（店の営業時間、価格、キャンペーン条件）
  - 逆に安全で効果が大きいのは、案を30個出させて自分が3個選ぶ使い方
- **クイズ**: なし

## 6. どのAI契約を選ぶか — 月3,000円の中身

- **図解案**: マトリクス（比較表を図として組む）。Claude Pro / ChatGPT Plus の2列 × 「月額」「得意」「デスクトップで作業を任せる機能」「初心者の入りやすさ」の4行。下段に Claude Code / Claude Cowork / Codex の位置づけを1行ずつ
- **本文で補う内容**:
  - どちらも月$20（日本のストア表示で3,000円前後）。**両方契約する必要はない。1つで足りる**
  - ざっくりの傾向: 短い投稿文・画像生成は ChatGPT、長い企画書・レポート・文章の推敲は Claude
  - Cowork / Code / Codex は「チャットの外でファイル操作まで任せる」機能。**運用代行の初月には要らない**。レポート作成が毎月の負担になってから触ればいい
  - AI未経験なら、まずチャット画面だけで1か月使う
  - 出典: Claude 公式プラン一覧、Claude Cowork ヘルプ
- **クイズ**: なし

### → クイズ2（AIの使いどころ）

「依頼主のカフェの新メニューを紹介する投稿をAIに書かせたい。正しいやり方は？」の3択。正答は「価格・原材料などの事実を自分で調べてプロンプトに入れてから書かせ、出てきた文を事実と照合する」。誤答肢に「AIに検索させて任せる」「そのまま投稿して間違いがあれば直す」。

## 7. 最初に打つプロンプト3本

- **図解案**: 階層スタック。プロンプトの4層 — ①役割（あなたは誰か）②前提（依頼主の情報・事実）③制約（文字数・トーン・禁止事項）④出力形式（何個・どんな形で）。層ごとに悪い例と良い例を1語ずつ添える
- **本文で補う内容**:
  - AI未経験がつまずくのは「命令が短すぎる」こと。「投稿文を書いて」では毎回ぼやけた文が出る
  - 実際に貼って使える3本を本文に載せる: **(a) 投稿ネタを30個出す** / **(b) 1本を投稿文に仕上げる** / **(c) 月次レポートの文章を作る**
  - 3本とも「事実は自分が入れる」構造にしてある
- **クイズ**: なし

## 8. 実績ゼロから最初の1件

- **図解案**: プロセスフロー（3ルート並列）。ルートA クラウドソーシング（初心者歓迎案件）／ルートB ココナラ出品／ルートC 知人の店を無料または低額で。3ルートの手前に「自分のアカウントを2か月運用する」という共通の前段を置く
- **本文で補う内容**:
  - 自分のアカウントが最初のポートフォリオになる。テーマは何でもいいが、依頼主が想像しやすい分野にする
  - ルートCが一番早いが、無料は1件だけ。2件目からは必ず有料にする（無料が実績にならない理由）
  - クラウドソーシングは手数料が引かれる。月3,000円の案件は手取りでもっと少ない
- **クイズ**: なし

## 9. 通る提案文・落ちる提案文

- **図解案**: Before/After 対比。左（落ちる）＝「未経験ですが頑張ります／勉強中です／何でもやります」。右（通る）＝「同業〇〇のアカウントを2か月運用し、保存数を月18→64に。あなたのお店なら〇〇の投稿を週3本提案します」
- **本文で補う内容**:
  - 依頼主が知りたいのは意欲ではなく「任せて数字が動くか」
  - 数字は小さくていい。フォロワー200人でも「増えた過程を説明できる」ことに価値がある
  - 提案文に必ず入れる3点: 具体的な数字 / その依頼主に固有の提案 / 稼働可能な曜日と時間
- **クイズ**: なし

### → クイズ3（提案文）

「提案文に書くと最も効果が高いのは？」の3択。正答は「自分が運用したアカウントの数値の変化」。誤答肢に「資格や受講した講座名」「対応可能な媒体の多さ」。

## 10. 扶養と税金 — 主婦がいちばん先に確認すること

- **図解案**: 分岐フローチャート。「副業の所得（収入−経費）」から分岐 — 20万円以下 → 所得税の確定申告は原則不要（ただし住民税の申告は必要）／20万円超 → 確定申告が必要。別軸で「年間収入の見込み130万円」→ 社会保険の扶養から外れる。業務委託は給与ではないので「106万円の壁」は原則かからない旨を注記
- **本文で補う内容**:
  - **所得税の話と社会保険の扶養の話は別物**。ここを混ぜると必ず間違える
  - 20万円ルールの「20万円」は売上ではなく所得（収入−経費）
  - 社会保険の扶養判定で引ける経費は「直接必要な経費」に限られ、通信費やPC代は認められないことが多い。**判定基準は健康保険組合ごとに違うので、配偶者の健保に直接聞く**
  - 106万円の壁（賃金要件）は2026年10月に撤廃予定。ただしこれは勤め先の給与の話
  - 出典: 国税庁 No.1900、厚生労働省「年収の壁」への対応、厚労省 被扶養者認定の通知
- **クイズ**: なし

## 11. 契約で決めておく5項目

- **図解案**: チェックリスト型のマトリクス。①業務範囲（やること／**やらないこと**）②投稿の最終承認は誰か ③報酬と支払日、修正回数の上限 ④アカウントのIDとパスワードの扱い、契約終了時の返却 ⑤炎上・クレーム時の責任分担
- **本文で補う内容**:
  - トラブルの大半は「どこまでが仕事か」の認識ずれ。**やらないことを書くのが効く**
  - 最終承認を依頼主に置くと、事故のときの責任が明確になる。初心者ほどここを譲らない
  - 個人間でも簡単な業務委託契約書を交わす。ひな形は無料で手に入る
- **クイズ**: なし

## 12. 投稿ボタンを押す前の3チェック

- **図解案**: プロセスフロー（3つのゲート）。①事実チェック（価格・日付・在庫はあるか）②権利チェック（写真・音楽・引用は使っていいものか）③表示チェック（広告なら「PR」と分かるか、効能を断言していないか）
- **本文で補う内容**:
  - ステマ規制（景品表示法、令和5年10月1日施行）で罰せられるのは**商品を売る事業者＝依頼主**。代行者は直接の名宛人ではないが、依頼主に違反させたら仕事は終わる
  - AI生成文で特に危ないのは「効果を断言する表現」。化粧品・健康食品・医療は薬機法の領域
  - 写真は依頼主から受け取ったものだけを使う。ネットで拾わない
  - 出典: 消費者庁 ステルスマーケティング規制ページ
- **クイズ**: なし

### → クイズ4（法令）

「ステマ規制で違反に問われるのは誰？」の3択。正答は「商品・サービスを供給する事業者（＝依頼主）」。誤答肢に「投稿を作った運用代行者」「SNSプラットフォーム」。解説で「だからこそ代行者はPR表記を提案する側に回る」と接続。

## 13. 最初の90日 — ロードマップ

- **図解案**: タイムライン。0〜30日「自分のアカウントを開設し週3投稿＋AIに慣れる」／31〜60日「数字を記録しポートフォリオ1枚を作る」／61〜90日「3ルートで応募、1件目を取る」／90日以降「2件目からは値上げ、レポートを付ける」
- **本文で補う内容**:
  - 最初の30日はお金にならない。ここで辞める人が多いので、あらかじめそう思っておく
  - 毎日やらない。週3投稿・週1分析を固定曜日に置く方が続く
  - 90日で1件取れなかった場合に見直す順番: 媒体 → 提案文 → 単価
- **クイズ**: なし

## 14. まとめ（カード3枚）

1. 相場は「会社向け」と「個人副業」で別。最初は月数千円から
2. AIは下書き係。事実確認と最終ボタンは人間が握る
3. 扶養・契約・法令の3点は、1件目を取る前に確認する
