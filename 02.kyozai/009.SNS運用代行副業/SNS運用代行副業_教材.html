AIと始めるSNS運用代行

SNSを運用したこともなく、副業もしたことがない人が、月3,000円のAI契約1つで最初の1件を取るまで。相場の現実、AIの線引き、扶養と契約の地雷を順に片づけます。

対象: 副業がはじめての人 レベル: 入門 所要 約40分 更新: 2026-08-14

この教材について

🎯

読み終えるとできるようになること

  1. SNS運用代行が「誰から・何を頼まれて・いくらもらう仕事か」を自分の言葉で説明できる
  2. AIに任せる作業と自分がやる作業の線引きができ、最初のプロンプトを実際に打てる
  3. 扶養・確定申告・契約という3つの地雷を避けて、最初の1件までの手順を紙に書ける
⚠️

この教材は「未経験から月30万」とは言いません。実際の初期単価は月3,000円台からです。夢を売るのではなく、始めた人が3か月で辞めないための順番を示します。

主な参照元: 総務省 情報通信メディアの利用時間と情報行動に関する調査 / 国税庁 No.1900 / 消費者庁 ステマ規制（全出典は末尾）

1. この仕事の全体像

SNS運用代行は「投稿を作って出す人」ではありません。依頼主の代わりにアカウントを育てる人です。依頼主が払うお金の根拠は、投稿の枚数ではなく「自分でやらずに済んだ時間」と「数字が動いたこと」の2つ。だから輪を1周させて、最後に数字を持って戻るところまでが仕事になります。

ここでAIの位置を先に決めておきます。AIが速いのは「案を出す」「文章にする」「まとめる」の部分だけ。依頼主と話す、事実を確認する、投稿ボタンを押す、数字を解釈して次を決める——この4つは人間の側に残ります。AIは輪を回す道具であって、輪そのものではありません。

💡

依頼主の多くは「SNSが大事なのは分かるが、毎日投稿する時間がない」個人店です。競合はプロの代理店ではなく、依頼主自身の「後でやろう」。だから完璧さより継続の方が売り物になります。

2. 何を代行するのか

案件は「全部お任せ」より「一部だけ」の方が多く出ます。未経験で入りやすいのは②制作・③投稿・④コメント返信。ここは手を動かせばできる作業で、依頼主から見れば「自分の時間が空く」ぶんだけで発注する価値があります。

いっぽう単価を左右するのは①企画と⑥レポートです。企画ができる人は「何を出すか」で悩む依頼主を助けられ、レポートが書ける人は「払っている意味」を依頼主に見せられます。作業だけの人は安く、判断ができる人は高い。この構図はどの受託仕事でも変わりません。

⚠️

「投稿だけ」で安く受けると、数か月後に①企画や⑤分析をタダで求められがちです。受ける範囲は最初に紙に書く。この続きは11章で扱います。

3. いくらもらえるのか

ネットで見かける「月20〜40万円」は、ほとんどが会社が会社に払う値段です。動画制作やレポート担当を含めた複数人のチーム費用で、個人が副業で受ける金額とは別の市場になります。この2つを混ぜて期待値を作ると、最初の案件を見た瞬間に心が折れます。

現実の入り口は、クラウドソーシングの初心者向け案件で1件あたり月3,000円前後。5件こなして月1.5万円という水準がよく報告されています。ここから副業として月1万〜10万円のレンジに上がるまで、おおむね3〜6か月かかると見ておくのが安全です。

単価が上がるきっかけは、実績の「数」ではありません。数字を説明できるようになったときです。「保存数が18から64になりました。理由はこの3本の投稿です」と言える人には、次の依頼主が値段を聞いてきます。

💡

クラウドソーシングは仲介手数料が引かれます。月3,000円の案件は手取りではさらに少なくなる。「最初は授業料」と割り切れる件数だけにして、長く低単価に留まらない設計にします。

理解度チェック 1

「SNS運用代行の相場は月20〜40万円」という記事を見ました。副業を始めるあなたの見立てとして正しいのは？

Bが正解。公開されている相場記事の多くは、制作会社が法人クライアントに提示する月額で、チームの人件費を含みます。Aは、実績があっても発注側の予算枠そのものが違うため成立しません。Cの地域差は、この2桁の差を説明する要因にはなりません。個人の副業は、まず月3,000円台の案件から始まると考えて計画を立てます。

4. どのSNSを選ぶか

利用率1位はLINE（91.1%）ですが、LINE公式アカウントの配信は別のスキル体系で、個人副業の入り口にはなりにくい媒体です。YouTubeも同じで、動画編集ができないと入れません。利用率が高い＝案件が取りやすい、ではないところが最初の落とし穴です。

未経験が最初に選ぶならInstagramが現実的です。飲食店・美容室・教室・小売といった小規模事業者の需要が厚く、写真と短い文章で成立するため、動画スキルがなくても始められます。慣れてきてから、同じ依頼主にリール（短尺動画）を足していく形にすると自然に単価が上がります。

そして1媒体に絞ること。複数を薄く触るより、1つで1年ぶんの季節・反応・失敗を知っている方が売り物になります。提案文でも「Instagramを1年やってきました」の方が「4媒体対応できます」より強い。

5. AIに任せること・任せないこと

AIは「思いつく速さ」と「書き出す速さ」を肩代わりする道具です。逆に肩代わりできないのが事実の保証。AIは依頼主の店の営業時間も、今月の価格も、在庫の有無も知りません。知らないまま、それらしい文章を書いてしまいます。ここが実務でいちばん事故になる場所です。

だから使い方は「AIが埋める欄」と「あなたが埋める欄」を分けることに尽きます。事実は自分が調べてプロンプトに入れ、AIには表現だけをやらせる。この形にすると、AIが事実を作る余地が消えます。

効果がいちばん大きいのは、右下の使い方——案を30個出させて、自分が3個選ぶ。人間が0から3個ひねり出すより速く、質も上がります。選ぶのは人間なので、外れ案が混ざっていても害はありません。

⚠️

AIが書いた文をそのまま投稿する運用は、事故が起きたときに説明ができません。とくに化粧品・健康食品・医療系は、効果を断言した一文で薬機法に触れます（12章）。

6. どのAI契約を選ぶか

日本から公式ページを開くと、Claude Pro は月$18、ChatGPT Plus は月3,000円と表示されます（2026年8月時点）。どちらも3,000円前後で、金額は選ぶ理由になりません。両方契約する必要はなく、1つで足ります。迷ったら、画像も一緒に作りたいなら ChatGPT、レポートや提案文の文章を整えたいなら Claude、という選び方でかまいません。あとから乗り換えても損はほとんどありません。

⚠️

金額は変わります。契約前に必ず自分で公式ページを見てください（Claude の料金プラン / ChatGPT の料金プラン）。表示のしかたが2つで違う点にも注意します。ChatGPT は日本語ページが円建て（月3,000円）なので毎月きっちり同じ額ですが、Claude はドル建てなので、請求される円の額が為替で毎月動きます。どちらも年払いにすると1か月あたりの単価は下がります。

Claude Code / Claude Cowork / Codex は、チャット画面の外でファイルを開いたり書き換えたりまで任せられる機能です。Cowork は Claude Pro に含まれ、Windows と macOS のデスクトップアプリで動きます。ただし運用代行の初月には要りません。先に覚えるべきは、チャット欄に何をどう書くかの方です。

💡

AIが初めてなら、最初の1か月はチャット画面だけを使ってください。毎月のレポート作成が「同じ作業の繰り返し」になってきたら、そのときに Cowork や Code を開くと、ありがたみが分かります。順番を逆にすると挫折します。

7. 最初に打つプロンプト3本

AIが初めての人がつまずくのは、命令が短すぎることです。「投稿文を書いて」だけでは、AIはどこかで見た平均的な文章を返します。逆に4つの層を埋めるだけで、出力は別物になります。以下はそのまま貼って使える3本。角かっこの中だけ、自分の依頼主の情報に置き換えてください。

(A) 投稿ネタを30個出すあなたは個人店のInstagram運用担当です。 【お店の情報】 ・業種：［例：住宅街のパン屋］ ・客層：［例：30〜40代の子育て世帯、平日の午前中が中心］ ・強み：［例：国産小麦・添加物なし・毎朝5時に焼く］ ・避けたい話題：［例：価格の安さを売りにしない］ 【依頼】 このお店のInstagramに投稿するネタを30個、箇条書きで出してください。 【条件】 ・30個のうち10個は「商品の紹介以外」にしてください ・専門用語を使わず、私が写真を用意できる範囲にしてください ・1個につき「投稿タイトル」と「なぜ刺さるか」を1行ずつ
(B) 1本を投稿文に仕上げる先ほどのネタのうち「［選んだネタ］」を投稿文にしてください。 【必ず使う事実】（これ以外の事実を書かないでください） ・商品名：［　］／価格：［　］（税込） ・販売日時：［　］ ・注意事項：［例：数量限定・予約不可］ 【条件】 ・本文は120字以内、絵文字は3つまで ・効果や効能を断言する表現は使わないでください ・ハッシュタグは10個、そのうち5個は投稿数の少ないものを提案してください ・3パターン出して、それぞれ「誰に向けた案か」を1行添えてください
(C) 月次レポートの文章を作るあなたはSNS運用の報告書を書く担当者です。 【今月の数字】 ・フォロワー：月初［　］人 → 月末［　］人 ・投稿数：［　］本／保存数の合計：［　］ ・いちばん伸びた投稿：［タイトル］（保存［　］） ・いちばん伸びなかった投稿：［タイトル］（保存［　］） 【依頼】 この数字をもとに、依頼主（SNSに詳しくない店主）向けの報告文を書いてください。 【条件】 ・「今月わかったこと」「来月やること」の2見出しで、各200字以内 ・専門用語は使わず、使う場合は括弧で説明を付けてください ・数字が悪い月でも、言い訳ではなく次の打ち手を書いてください

3本とも、事実の欄はあなたが埋める構造になっています。AIに「調べておいて」と頼まない。この一点を守るだけで、事故の大半は起きなくなります。

理解度チェック 2

依頼主のカフェの新メニューを紹介する投稿をAIに書かせます。いちばん安全で実務的なやり方は？

Cが正解。AIは依頼主の最新の価格や提供条件を知らないため、事実は人間が入れるのが原則です。Aは、AIが古い情報や別店舗の情報をそれらしく書いてしまう典型的な事故パターン。Bは、間違った価格を出した時点で依頼主の信用問題になり、修正しても「一度出た」事実は消えません。事実は入力側で固定し、AIには表現だけを任せます。

8. 実績ゼロから最初の1件

実績がない状態で応募しても通りません。だから自分のアカウントを最初のポートフォリオにします。テーマは何でもよいのですが、狙う依頼主が想像しやすい分野にすると転用が効きます。パン屋を狙うなら「近所のパン屋めぐり」、教室を狙うなら「子どもの習い事記録」といった具合です。

2か月ぶん、週3投稿を続けると数字が動きます。フォロワー200人でもかまいません。大事なのは数の大きさではなく、増えた過程を説明できること。「この3本が伸びた、理由はこう考えている」と言えれば、それが実力の証明になります。

ルートCが最短ですが、無料でやるのは1件だけにしてください。無料の仕事は「無料でやってくれる人」という実績にしかならず、2件目も無料を期待されます。1件目が終わったら数字を持って「来月から月◯円でお願いします」と切り出す。ここで言えないと、ずっと言えません。

9. 通る提案文・落ちる提案文

提案文で落ちる原因はほぼ1つ、誰にでも送れる文になっていることです。「未経験ですが」「勉強中です」「何でもやります」は、受け取る側から見ると判断材料がゼロ。意欲は伝わりますが、意欲で発注する人はいません。

入れるべきは3点だけです。①自分が運用したアカウントの数値の変化（小さくてよい）、②その依頼主のアカウントを見たうえでの具体的な提案（1つでよい）、③稼働できる曜日と時間帯。③は軽視されがちですが、家庭と両立する副業では信用に直結します。「平日の午前中に作業し、返信は当日中」と書ける人は、返信が読めない人より強い。

💡

提案文はAIに下書きさせて構いませんが、②だけは自分で書いてください。依頼主のアカウントを実際に見ないと書けない部分で、そこが読まれています。AIに書かせると必ず一般論になります。

理解度チェック 3

未経験のあなたが提案文に書いたとき、いちばん採用率を上げるのはどれ？

Bが正解。依頼主が判断したいのは「任せて数字が動くか」の一点で、それを示せるのは実際に動かした数字だけです。Aの講座名は、依頼主にとって成果と結びつかない情報で、修了証は投稿の質を保証しません。Cの多媒体対応は、未経験者が書くと「どれも浅い」と読まれやすく、1媒体を1年やった人に負けます。数字は小さくてよいので、変化と理由をセットで書きます。

10. 扶養と税金

主婦が副業を始めるとき、いちばん先に確認すべきはここです。そして最も多い誤解が「税金の話」と「扶養の話」を1本の線で考えてしまうこと。この2つは所管も基準も別なので、それぞれ独立に判定されます。

まず所得税。給与を1か所から受けている人は、副業の所得が年20万円を超えると確定申告が必要です（国税庁 No.1900）。この「20万円」は売上ではなく所得＝収入−経費。月3万円の案件を年間続けて売上36万円でも、経費が20万円あれば所得は16万円です。なお20万円以下で所得税の申告が不要な場合でも、住民税の申告は別途必要になります。

次に社会保険の扶養。こちらは「今後1年間の収入見込みが130万円未満」が基本線です。注意すべきは経費の扱いで、扶養の判定では「直接必要な経費」しか差し引けません。仕入れのような費用は引けても、通信費・パソコン代・広告費などは認められないことが多い。つまり確定申告で使う経費と、扶養判定で使える経費は別物です。

そして「106万円の壁」。これは勤め先で厚生年金・健康保険に入る賃金要件の話で、業務委託の副業には原則かかりません。なおこの賃金要件自体、2026年10月に撤廃される予定です。

⚠️

扶養の判定基準は健康保険組合ごとに運用が違います。ネット記事や本教材の説明だけで判断せず、配偶者の勤務先の健保に「業務委託で収入がある場合の判定方法と、引ける経費の範囲」を必ず直接確認してください。ここだけは人に聞くのが最短です。

11. 契約で決めておく5項目

個人どうしのやりとりでも、簡単な業務委託契約書は交わします。無料のひな形が公開されているので、それを埋めるところから始めれば十分です。争いのほとんどは「どこまでが仕事か」の認識ずれで起きるので、①が最重要になります。

①でとくに効くのが「やらないこと」を書く欄です。「写真の撮影は含まない」「広告の運用は含まない」「電話でのクレーム一次対応は含まない」——書いてあれば断れます。書いていないと、断ったときに「冷たい人」になってしまう。

②の最終承認は、初心者ほど依頼主側に置いてください。自分に承認権があると、投稿内容の誤りがそのまま自分の責任になります。承認を挟むと納品は少し遅くなりますが、事故ったときに立場を守れる方がはるかに大きい。

④は見落とされがちです。パスワードをメッセージアプリに平文で送らない、契約終了時には権限を外す。アカウントは依頼主の資産という前提を、最初に文章で確認しておきます。

12. 投稿する前の3チェック

①事実——AIの下書きは、価格や日付をそれらしく埋めてきます。依頼主に確認していない数字が1つでも残っていたら投稿しない。これが最頻出の事故です。

②権利——写真は依頼主から受け取ったものだけを使います。ネットで拾った画像、他店の写真、音源つきの動画は触らない。デザインツールのテンプレート素材を使う場合も、素材そのものの転売や、テンプレートを文字だけ差し替えて納品する使い方は規約に触れることがあります。

③表示——ステルスマーケティング規制（景品表示法）は令和5年10月1日施行で、広告であることを隠した表示が違反になります。ここで押さえておきたいのは、規制の名宛人は「商品・サービスを供給する事業者」＝依頼主だという点です。代行者は直接の処分対象ではありません。ただし依頼主に違反させたら、その仕事は終わります。だから代行者は「これはPR表記を入れましょう」と提案する側に回るのが正解です。

あわせて、化粧品・健康食品・医療系で効果を断言する表現は薬機法の領域に入ります。「シミが消える」「痩せる」「治る」はAIがうっかり書きがちな言い回しなので、プロンプトの制約欄に「効果や効能を断言しない」と毎回入れておきます。

理解度チェック 4

ステマ規制（景品表示法）で違反に問われるのは誰でしょう？

Cが正解。消費者庁は「規制の対象となるのは、商品・サービスを供給する事業者（広告主）」と明示しており、インフルエンサーなどの第三者は対象外とされています。Aの運用代行者は直接の処分対象ではありませんが、依頼主を違反させれば契約は続きません。Bのプラットフォームも名宛人ではありません。だからこそ代行者の実務上の役割は、依頼主に「ここはPR表記が要ります」と提案する側に回ることになります。

13. 最初の90日

辞める人がいちばん多いのは最初の30日です。投稿しても反応がなく、収入もない期間だから。ここは無収入と決めておくと、心理的に耐えられます。逆にここを飛ばして応募だけ先に始めると、提案文に書ける数字がなくて落ち続け、余計に折れます。

続けるコツは、毎日やらないことです。週3投稿・週1分析を、固定の曜日に置く。「火・木・土に投稿、日曜の夜に数字を見る」のように生活に埋め込むと、やる気に依存しなくなります。家庭と両立する副業では、これが最大の技術です。

90日で1件も取れなかった場合、見直す順番は①媒体 → ②提案文 → ③単価。単価から下げるのは最後にしてください。安くして取った1件目は、そのまま自分の相場になります。
