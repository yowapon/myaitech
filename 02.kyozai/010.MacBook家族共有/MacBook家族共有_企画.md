# 教材企画: はじめてのMacBookを家族で共有する — Macのユーザアカウントと Apple アカウント

## 0. 前提

- **対象読者**: Windows PC は日常的に使えるが、Mac は触ったことがない人。iPhone は本人も家族もそれぞれ持っていて、Apple アカウント（旧 Apple ID）は各自が既に持っている
- **想定レベル**: 入門。専門用語は初出で必ず言い換える
- **所要時間**: 約25分
- **想定シーン**: 家に MacBook を1台買った。父・母・子2人の4人で、アカウントを切り替えながら使いたい
- **ゴール（読了後にできること）**
  1. 「Macのユーザアカウント」と「Apple アカウント」が別物だと、人に説明できる
  2. **電源オフの状態から自分の画面を出すのに、どちらのパスワードを何回入れるのかが分かる**
  3. 家族4人で1台を使うとき、誰にどのアカウントを作ればいいか自分で決められる
  4. Apple アカウントを家族で使い回してはいけない理由と、代わりに使う「ファミリー共有」が分かる

### 切り口の方針

- **Windows との対比を各所に置く。**読者の頭の中にある Windows の地図を、Mac の地図に描き直させるのがこの教材の仕事
- 一番の混乱ポイントは「iPhone で使っている Apple アカウント＝Mac のログインアカウント」だと思い込むこと。ここを2章で正面から潰す
- 抽象論を避け、**4人家族の設計表**という具体物を軸にする

---

## 1. 全体像 — 1台のMacBookは「2階建て」

- **図解案**: 2層構造図。下層＝MacBook本体に4つのユーザアカウント（父・母・長男・次男）が並ぶ。上層＝各アカウントの中からそれぞれ別の Apple アカウントへ線が伸びてクラウドにつながる
- **伝えること**: アカウントは2種類あって、階層が違う。Macのユーザアカウント＝端末の中の自分の区画。Apple アカウント＝Apple のサービス側の会員証
- 本文: 図の「2階建て」がこの教材の背骨だと宣言する。以降の章はすべてこの図のどこかの話

## 2. 2つのアカウントの正体（Windowsと並べる）

- **図解案**: 2列の対比マトリクス。左＝Windows（ローカルアカウント / Microsoftアカウント）、右＝Mac（ユーザアカウント / Apple アカウント）。同じ役割どうしを横線でつなぐ
- **伝えること**:
  - Macのユーザアカウント ≒ Windowsのローカルアカウント（この1台の中だけの存在。デスクトップ・書類・設定を分ける）
  - Apple アカウント ≒ Microsoft アカウント（会社のサービスに入るための会員証。App Store・iCloud・iMessage・「探す」）
- 本文: 役割で対応づけると迷わない。ただし**Windowsは両者を合体させるのが既定、Macは常に別々**という違いがある（→3章）

## 3. Windowsユーザーが必ず一度つまずくところ

- **図解案**: 鍵2本の図。「Macのログインパスワード（この端末を開ける鍵）」と「Apple アカウントのパスワード（Appleのサービスを開ける鍵）」を並べ、それぞれ何を開けるかを右側に描く
- **伝えること**:
  - Windows 11 は初期設定で Microsoft アカウントによるサインインを勧めてくるので、「PCのログイン＝Microsoftアカウント」が一体に見える
  - Mac は違う。ログイン時に入れるのは**その端末のユーザアカウントのパスワード**で、Apple アカウントのパスワードではない
  - 実際、Apple アカウントにサインインしなくても Mac は普通に使える
- クイズ1: 「Macのログイン画面で入れるパスワードはどれか」

## 4. Macのユーザアカウントは4種類

- **図解案**: 権限マトリクス（表形式のSVG）。行＝管理者／通常／共有のみ／ゲスト、列＝ログインできる／アプリを全体に入れられる／他人のアカウントを作れる／設定を変えられる。○×で埋める
- **伝えること**: Apple公式の定義に沿って4種類。家族運用では**管理者は1〜2人、あとは通常**が基本形
- 出典: Apple「Macのユーザ、ゲスト、およびグループを設定する」

## 5. 4人家族の設計表（この教材の核）

- **図解案**: 設計表のSVG。4人分の行で、「Macのユーザアカウント種別」「Apple アカウント」「主な用途」を並べる
- **伝えること**: 具体例。父＝管理者、母＝通常、長男（15歳）＝通常＋本人の Apple アカウント、次男（10歳）＝通常＋お子様用 Apple アカウント
- 本文: なぜ全員を管理者にしないのか（誤操作と、子どもが自分で制限を外せてしまう）

## 6. セットアップの順番（初回だけ・4ステップ）

- **図解案**: プロセスフロー。① 箱を開けて最初の1人（管理者）を作る → ② システム設定でユーザを人数分追加 → ③ 各自が初回ログインして自分の Apple アカウントでサインイン → ④ 管理者がファミリー共有をつくる
- **伝えること**: 順番が大事。③を飛ばして先に④はできない
- 本文: ②③はそれぞれ数分。**③は本人にやらせる**（パスワードを親が知る必要はない）。**この4ステップは初回だけ**だと明記して7章へ渡す

## 7. 電源オフから自分の画面が出るまで（★読者からの要望で追加）

- **図解案**: プロセスフロー4ステップ ＋ 下に注記バンド2本。① 電源ボタン → ② ログイン画面に家族4人の名前 → ③ **Mac のログインパスワード**を入力（この箱だけ強調） → ④ 自分のデスクトップ。下の緑バンド「この4ステップに Apple アカウントは出てこない」、琥珀バンド「Touch ID が使えるのは2回目から」
- **伝えること**: 電源が完全に切れた状態から自分の画面を出すのに入れるのは Mac のユーザアカウントのパスワード1つだけ
- 落とし穴: 電源投入・再起動・ログアウト後の**1回目だけ Touch ID が使えない**（Apple の仕様）
- 出典: Apple「MacでTouch IDを使う」

## 8. Apple アカウントを入れるのは、いつ？（★読者からの要望で追加）

- **図解案**: 3行の一覧（左＝場面ラベル／右＝入力するもの）。「初回だけ」＝ログインパスワードを決める＋Apple アカウントでサインイン／「2回目以降・毎日」＝ログインパスワードだけ／「ときどき」＝App購入・新端末追加・iCloud設定変更
- **伝えること**: **「毎回ユーザアカウント → Apple アカウント」と2回入れる必要はない。**Apple アカウントは初回セットアップの1回だけ
- 補足: 設定アシスタントは「Apple ID でサインイン → コンピュータアカウントを作成」の順。サインインは飛ばしてもよく、あとからシステム設定でできる
- クイズ2: 「翌日、電源の切れた Mac を使うとき入力するものは？」

## 9. ファストユーザスイッチ — ログアウトしないで切り替える

- **図解案**: Before/After。左＝ログアウト方式（アプリを全部閉じる→別人がログイン）、右＝ファストユーザスイッチ（作業を開いたまま並列に保持）
- **伝えること**: Windowsの「ユーザーの切り替え」と同じ発想。メニューバーかコントロールセンターから切り替える。有効化はシステム設定＞メニューバー
- 注意: 複数人がログインしたままだとメモリを食う。別の人がログイン中はシャットダウンに確認が出る
- 出典: Apple「Macで素早くユーザを切り替える」
- クイズ3: 「ファストユーザスイッチで切り替えたとき、前のユーザーのアプリはどうなるか」

## 10. ファミリー共有 — 共有されるものと、されないもの

- **図解案**: 分解ツリー。中央「ファミリー共有（最大6人）」から左右に分岐。左＝共有される（iCloud+の容量／購入したApp・音楽・本／Appleのサブスク／位置情報／スクリーンタイム）、右＝共有されない（写真ライブラリ／メッセージ／メール／連絡先／各自のiCloudデータ）
- **伝えること**: ここが最大の誤解ポイント。**共有されるのは「支払いと権利」であって「データ」ではない**
- 出典: Apple「ファミリー共有」

## 11. iCloud+ の容量を家族で分け合う

- **図解案**: バーチャート。50GB/200GB/2TB/6TB/12TB の月額を横棒で比較。「1人ずつ契約」vs「1つを6人で分ける」の注記
- **伝えること**: iCloud+ はどのプランも最大5人の家族と共有できる。人数が増えても料金は増えない。無料枠は5GBしかないので、Macを使い始めると足りなくなる
- 出典: Apple「iCloud+」公式ページ（2026年8月時点の日本円価格）
- クイズ4: 「ファミリー共有で200GBプランを共有したら、家族の写真は互いに見えるか」

## 12. やってはいけない — 1つの Apple アカウントを家族で使い回す

- **図解案**: Before/After（悪い例→良い例）。左＝1つのアカウントを4人が使う（写真が混ざる／iMessageが全端末に届く／子の購入が親のカードに）。右＝4アカウント＋ファミリー共有
- **伝えること**: 「アカウントを分けると課金が4倍になる」という誤解が、使い回しの動機になっている。実際はファミリー共有で解決する
- 本文: Apple自身が「Everyone should have their own Apple Account」と明記している

## 13. FileVault は入れる・入れないを選べる

- **図解案**: 2列の対比（オフのまま／オンにする）。**「オフのまま」側を緑にする**——必須に見せないため。それぞれ「向いているのは」を1行添える
- **伝えること**: **FileVault はオンにしなくてもよい。**Apple シリコン／T2 搭載機では内蔵ストレージは初めから自動で暗号化されていて、Apple 自身が FileVault は任意だと書いている
- FileVault が足すのは「ログインパスワードを知っている人でないと解けない」という条件。Windows の BitLocker に相当
- 判断基準は表で: 家に置く→オフでよい／持ち歩く→オン／Intel（T2なし）→オン
- 注意は**オンにする場合だけ**に限定して warn callout に隔離: 家族全員に解錠許可（忘れると本人が入れない）、復旧キーの保管場所
- 出典: Apple「MacのFileVaultで起動ディスクを暗号化する」

## 14. 家族どうしでファイルを渡す

- **図解案**: フォルダ構造図。/Users/ の下に父・母・長男・次男・Shared が並び、Shared だけが全員から矢印で結ばれる。各ホームの Public/Drop Box も描く
- **伝えること**: 別ユーザーのホームフォルダは原則見えない。渡したいものは `/Users/Shared`（Windowsの「パブリック」フォルダーと同じ役割）か、相手の Public 内 Drop Box に置く
- 注意: Shared に置いたファイルは、作った本人以外は書き換えられないことがある
- クイズ5: 「別ユーザーに大きな動画ファイルを渡したいときの正しい方法」

---

## まとめカード4枚

1. **2階建て** — 端末のユーザアカウントと、Appleの会員証。混ぜない
2. **毎日入れるのは1つだけ** — 起動時は Mac のログインパスワードのみ。Apple アカウントは初回だけ
3. **1人1アカウント** — Apple アカウントは使い回さない。分けたうえでファミリー共有でつなぐ
4. **共有されるのは支払い** — 容量とサブスクと購入権。写真とメッセージは各自のまま

最後の callout は「買った日にやること」「翌日からやること」の2段に分けて、初回と日常の違いを最後にもう一度示す。
