パスキー入門 —
「別のPCから入れない」の正体

スマホでは指紋ひとつで入れるのに、別のパソコンからだと「パスキーを登録してください」と言われる。あの不親切なメッセージの意味を、仕組みから解く。

対象: 中学生〜高校生 レベル: 入門 所要 約15分 更新: 2026-08-10

この教材について

🎯

読み終えるとできるようになること

  1. パスキーの正体を「鍵と鍵穴」で説明できる
  2. パスキー／Windows Hello／PIN／iCloudキーチェーンの関係を区別できる
  3. 別のPCから入りたいときの2つの解決策を自分で選べる

主な参照元: FIDO Alliance / 野村證券 オンラインサービス ヘルプ（全出典は末尾）

1. パスワードの弱点

パスワードは合言葉だ。だから一度盗まれると、サービス側から見て偽者と本人の区別がつかない。しかも人間は覚えきれないので使い回す。1か所漏れれば全部が開く。

📈

国内のフィッシング報告は2025年12月の1か月だけで190,500件（フィッシング対策協議会）。「気をつける」で防ぐには数が多すぎる。

2. パスキーは2つで1組の鍵

パスキーは覚える文字列ではなく、数学的にペアになった2本の鍵だ。公開鍵はサービスに預ける鍵穴なので、漏れても悪用できない。秘密鍵は端末の中から一度も外に出ない。だから「サービスが攻撃されてパスワードが流出」に相当する事故が原理的に起きない。

3. ログインの中で起きていること

顔や指紋はサイトに送られていない。端末のロックを開けるために使われるだけだ。さらに署名は「そのサイト専用」に作られるので、偽サイトに渡しても本物では通用しない。人間が見抜けなくても、機械が相手を間違えない。

4. 秘密鍵は「保管庫」に入る

混乱の原因は、4つの言葉を同じ仲間だと思ってしまうことにある。実際には階層が違う。

言葉正体階層
パスキー秘密鍵と公開鍵のペア中身
iCloudキーチェーンApple製の保管庫入れ物
Windows HelloMicrosoft製の保管庫入れ物
Windows PINその保管庫を開ける暗証番号開け方
理解度チェック 1

パスキーの「秘密鍵」はどこにあるか。

秘密鍵は端末を出ないので、サービス側に置かれることも送られることもない。Aだとサービスの流出で全員の鍵が漏れてしまい、パスワードと同じ弱点になる。Cは通信を盗聴されれば終わりで、これも成立しない。サービスが持つのは公開鍵だけだ。

5. Windows Hello と PIN

Windows HelloはWindowsに内蔵された保管庫で、顔・指紋・PINで開ける。PINが短くてよいのは、そのPC以外では意味を持たない数字だからだ。TPMという専用チップが中で守り、連続で間違えるとロックされる。PINはパスキーの代わりではなく、保管庫の開け方にすぎない。

6. iCloudキーチェーン

iCloudキーチェーンはAppleの保管庫だ。同じApple IDのiPhone・iPad・Macなら、1台で作ったパスキーが自動で他にも現れる。ここまでは快適だが、この輪はAppleの外へは広がらない。Windowsから見ると、iPhoneの中のパスキーは存在しないのと同じだ。

理解度チェック 2

iPhoneで登録したパスキーが、Windows PCのログイン画面に出てこないのはなぜか。

保管庫はメーカーごとに分かれていて、その境界を越えて中身が移ることはない。Aは誤りで、パスキーに有効期限はない。Bも違って、Edge・Chrome・Firefoxはいずれも対応済み。対応していないのはブラウザではなく、保管庫どうしの関係だ。

7. なぜ別PCで「登録しろ」なのか

これが冒頭の謎の答えだ。サイトはあなたを疑っているのではない。いま操作しているPCの保管庫に、鍵が1本も入っていないのを見ているだけ。だから「パスキーを登録してください」は「このPCにも合鍵を作ってください」という意味になる。

💡

そして合鍵を作らずに、iPhoneの鍵をその場だけ借りる道もある。次の2つが解決策だ。

8. 解決A: QRコードで借りる

PCの画面にQRコードを出し、iPhoneで読み取る方法だ。ここでのBluetoothはデータの通り道ではなく、2台が本当に近くにあることの証明に使う。遠くの誰かがQR画像だけ手に入れても成立しない。PCには何も残らないので、学校や家族共用のPCならこれが正解。

⚠️

両方の端末でBluetoothをオンにしておく必要がある（野村證券も同じ案内をしている）。

理解度チェック 3

QRコードでログインするとき、Bluetoothは何のために使われるか。

Bluetoothは近さの確認専用で、これがあるから遠隔地からの成りすましが防げる。Aは仕組みの根本に反する——秘密鍵は端末を出ないという約束が崩れてしまう。Cも違い、実際のやり取りは暗号化されたインターネット経由で行われる。

9. 解決B: そのPCにも登録する

自分だけが使うPCなら、追加登録しておくと次からPINや指紋だけで入れる。登録の入口では保管先を選ぶことになる。EdgeやFirefoxならWindows Hello、ChromeならGoogleパスワードマネージャーが素直だ（後者はGoogleアカウントに紐づくので、別のPCのChromeでもそのまま使える）。

🔁

追加登録には、いま使えるパスキーなど既存の方法での本人確認が必要。「鍵が1本もない状態」を作らないため、予備は元気なうちに。

10. どちらを選ぶか

迷ったらQRで借りればいい。損をしないし、いつでも後から登録できる。逆に、共用PCに合鍵を作るのは避ける。パスキーは端末に住みつく鍵だからだ。

🧯

スマホを買い替える前に、必ずPCなど別の場所にもパスキーを用意しておく。1本しかない鍵を失くすと、書類の郵送などやり直しになる。

まとめ

パスキー＝出ていかない鍵

秘密鍵は端末の中。送られるのは署名だけなので、偽サイトに渡しても通用しない。

Hello・キーチェーンは入れ物

鍵をしまう保管庫。PINはその扉を開ける番号で、鍵そのものではない。

「登録して」＝合鍵を作れ

そのPCの保管庫が空なだけ。QRで借りるか、追加登録するかの二択。
