# 教材企画: 株式投資入門 — 株のもうけは「5つの部品」でできている

## 0. 前提

- **対象読者**: 高校生（および「株はまったくの素人」という大人。18歳から自分で証券口座を作れる年齢層）
- **想定レベル**: 入門。金融・会計・数学の前提知識ゼロ。使う計算は掛け算と割り算だけ
- **所要時間**: 約20分
- **切り口**: 「株とは何か」を並べるだけの用語集にしない。**株のもうけを1本の式に分解し、そのうち自分がコントロールできる項だけを鍛える**という一本の背骨を通す。用語（EPS・PER・配当利回り・信託報酬・20.315%・NISA）は全部この式のどこかの部品として登場させる
- **ゴール（読了後にできるようになること）**
  1. 株価が上がる理由・下がる理由を「利益」「人気」「時間」に分解して説明できる
  2. リスクという言葉を「危険」ではなく「値段のブレ幅」として正しく使える
  3. 自分にコントロールできること（コスト・税金・分散・時間・行動）と、できないこと（明日の株価）を仕分けできる

## この教材の背骨

読者がつまずく本当の理由は「株は上がるか下がるかの2択のゲーム」だと思っていること。実際には、もうけは次の足し算・引き算でできている。

> **もうけ ＝ ①会社の利益の伸び ＋ ②配当 ± ③人気（PER）の変化 − ④コスト − ⑤税金**
> （そして①②を雪だるまにするのが **⑥時間＝複利**）

| 部品 | 正体 | 自分でコントロールできるか |
|---|---|---|
| ① 利益（EPS） | 会社が実際に稼いだ額 | ✕ できない |
| ② 配当 | 利益のうち株主に配られる分 | ✕ できない |
| ③ 人気（PER） | みんながその利益に何倍払うか | ✕ できない（一番暴れる） |
| ④ コスト | 手数料・信託報酬 | **○ 選ぶだけで決まる** |
| ⑤ 税金 | 20.315%。NISAならゼロ | **○ 口座を選ぶだけ** |
| ⑥ 時間・分散・行動 | 複利／1社に賭けない／売らない | **○ 高校生の最大の武器** |

「①②③は運、④⑤⑥は実力」——この仕分けを最初に立てて、以降のセクションを全部ここに紐づける。ノウハウとは④⑤⑥のことである、というのがこの教材の主張。

## 1. 株を買う＝会社の「取り分」を買う

- 図解案: **分解ツリー**。会社（発行済株式 1,000株）→ 1株 → その1株が持つ3つの権利（利益の取り分／配当を受け取る／株主総会で投票）
- 伝えること: 株は「値札のついたカード」ではなく会社の所有権の1切れ。だから会社が稼げば取り分が増える
- 本文で補う内容: 単元＝100株が基本だが、いまは1株から買える（単元未満株）。文化祭の屋台に出資して売上を山分けするのと同じ構造
- 用語: 株主 / 単元株 / 配当 / 議決権

## 2. 【背骨】もうけは5つの部品でできている

- 図解案: **式の分解図**。中央に大きく「もうけ」、そこから ①利益 ②配当 ③人気 −④コスト −⑤税金 が枝分かれし、下段に「運のゾーン（①②③）」「実力のゾーン（④⑤）」を色分けした帯を敷く
- 伝えること: 株価予想が当たらないのは、当たらない部品（③人気）に賭けているから。教材の残りは各部品を1つずつ見ていく
- 本文: 200字。「以降のセクションはこの図のどの部品の話か、毎回冒頭に示す」と宣言
- クイズ1: 株価が上がる理由として「部品」に当てはまらないものはどれか

## 3. 部品① 利益 — 会社が稼ぐと、株は本当に増える

- 図解案: **プロセスフロー（4段）**。売上 → 費用を引く → 利益 → 発行済株式数で割る＝EPS（1株あたり利益）。最後の箱に「これがあなたの取り分」
- 伝えること: EPSが2倍になれば、人気（PER）が同じでも株価は理屈上2倍。株式投資の土台はここだけ
- 本文: 200字。長期で見れば株価はEPSについていく、というのが唯一のまともな根拠
- 数字: 米国株（S&P500）の1926〜2025年の平均年率 約10.3%、インフレ調整後で約7%

## 4. 部品③ 人気 — 同じ利益でも株価が変わる（PER）

- 図解案: **掛け算のマトリクス**。株価 ＝ EPS × PER。EPS 100円は同じでも PER 10倍なら1,000円、PER 30倍なら3,000円、という3列の比較図
- 伝えること: PERは「その会社の利益の何年分まで払っていいと思われているか」という人気投票の点数。決算が何も変わらなくても株価が動く犯人はこれ
- 本文: 200字。短期の値動きの大半は③、長期の結果の大半は①。だから「短期は予想不能・長期は少しマシ」になる
- 用語: PER / EPS / 配当利回り（②の測り方として1行）

## 5. リスクの正体は「危険」ではなく「ブレ幅」

- 図解案: **レンジ図（縦の振れ幅バー）**。2026年の日経平均：年初来安値 50,558.91円（3/31）→ 年初来高値 72,831.73円（6/22）→ 直近 66,970.22円。安値から高値まで **+44%** 動いたことを1本のバーで見せる
- 伝えること: 同じ1年の中でこれだけ動く。上にも下にも動くから「ブレ幅」。ブレるからこそ長期のリターンが預金より高い（ブレの対価がリターン）
- 本文: 200字。「リスクを取る＝危ないことをする」ではなく「値段が上下するのを受け入れる」
- クイズ2: リスクという言葉の意味として正しいのはどれか

## 6. 部品⑥ 時間 — 高校生だけが持っている武器

- 図解案: **バーチャート**。毎月1万円を年率5%で積み立てた場合の到達額（教材側の試算と明記）。10年→約155万円 / 20年→約411万円 / 30年→約832万円 / 40年→約1,526万円。投じた元本（120/240/360/480万円）を薄い色で重ねて「差＝複利」を見せる
- 伝えること: 元本は年数に比例、結果は年数に指数で効く。18歳と30歳の差12年は、最後の12年ぶんの一番太い部分を丸ごと失うこと
- 本文: 200字。72の法則（72 ÷ 年率 ＝ 2倍になる年数。5%なら約14年）
- 数字: 金融庁の試算——国内外の株式・債券に毎月同額積立を続けた場合、保有5年では年率−8%〜+14%とばらつくが、保有20年では+2%〜+8%に収まり元本割れなし

## 7. 分散 — 1社に賭けない

- 図解案: **比率バー＋対比**。上段「1社に100%」→ その1社が半減すると全体−50%。下段「500社に分散（インデックス）」→ 1社が半減しても全体−0.1%。同じ「半減」が全体に与える影響の違いを長さで見せる
- 伝えること: 分散はリターンを上げる技ではなく、**再起不能を防ぐ技**。投資信託＝みんなのお金をまとめて数百〜数千社に自動で分ける箱
- 本文: 200字。インデックスファンド＝市場全体をまるごと買う。個別株を当てにいくのは「上級者の遊び」で、資産形成の本線ではない
- クイズ3: 暴落したときの正しい行動

## 8. 部品④⑤ コストと税金 — 唯一「確実に」効くノウハウ

- 図解案: **Before/After 対比**。左：課税口座（利益100万円 → 税金20.315万円 → 手取り79.7万円）／右：NISA（利益100万円 → 税金0円 → 手取り100万円）。あわせて信託報酬 0.05775% と 2% の30年後の差を小さな注記で
- 伝えること: 株価は当てられないが、コストと税金は買う前に確定している。ここだけは100%自分の意思で決まる
- 本文: 200字。新NISA＝つみたて投資枠120万円/年＋成長投資枠240万円/年、生涯1,800万円（成長枠は1,200万円まで）、非課税期間は無期限
- 用語: 信託報酬 / 20.315%（所得税15%＋復興特別所得税0.315%＋住民税5%）/ 特定口座（源泉徴収あり）

## 9. 一番の敵は自分 — 下がったときに脳が何をするか

- 図解案: **ループ図（悪循環）**。SNSで話題を見る → 高値で買う → 下がる → 怖くて売る → 上がったのを見て後悔 → また話題に飛びつく、の4〜5段サイクル。中央に「安く売って高く買う」の文字
- 伝えること: 初心者が負ける理由は知識不足ではなく、恐怖と欲で売買のタイミングが逆になること
- 本文: 200字。対策は「判断の回数を減らす」——自動積立、見る頻度を下げる、売るルールを先に決める
- クイズ4: 積立投資（ドルコスト平均法）が効く理由

## 10. 18歳の壁と、いま高校生ができること

- 図解案: **タイムライン＋プロセスフロー**。上段タイムライン：〜17歳（未成年口座・親の同意／2027年1月からこどもNISA）→ 18歳の1月1日（NISA口座が持てる）。下段フロー：①証券口座を作る → ②入金 → ③積立の設定 → ④触らない
- 伝えること: NISAは「その年の1月1日時点で18歳以上」が条件（誕生日ではない）。それまでにできる最強の準備は、少額で1株買って値動きを体感しておくこと
- 本文: 200字。1株から買える証券会社があり、数百円〜数千円で株主になれる。ただし単元未満株は手数料・スプレッドが割高になりがちで、株主優待は原則100株から
- 注意: 儲け話・SNSの「必ず上がる」・元本保証をうたう勧誘は詐欺、をcalloutで1行
